# Technical Appendix: Guide to the MATLAB Replication Folder

This note maps the main MATLAB scripts to the figures and tables in the thesis and describes how to run them. The thesis uses a two-step SVARX analysis of geopolitical risk shocks, a LASSO-based robustness specification, and single-equation ADL impulse responses. The code for the nonlinear shock transmission analysis refers to Forni et al. (2024); the ADL analysis refers to Baek and Lee (2022). The application, data, and reported results are those of this thesis.

## Running the folder

Set the MATLAB current directory to the replication folder before running a script. Keep its `Data` and `Functions` subfolders in place, along with the `.mat` files and country-specific data scripts called by the programs. Scripts that contain `addpath('Data')` and `addpath('Functions')` expect those directories relative to the current directory. For example:

```matlab
cd('/path/to/replication-folder')
addpath('Data')
addpath('Functions')
Fig123
```

Run each top-level script by entering its filename without the `.m` suffix. The scripts generate figures in MATLAB or print table output according to their own commands. A displayed figure is not necessarily exported to disk; use the script's save command, if present, or export the figure from MATLAB. Recheck the input paths and required helper functions if a script stops before producing output.

## Method and code references

In the SVARX analysis, a preliminary VAR identifies a GPR innovation. The innovation and its square then enter the response system as exogenous terms, so the linear, quadratic, and combined contributions can be shown separately (see thesis Section 3.2 and Figures 8–10). This implementation takes methodological and MATLAB-code inspiration from Forni et al. (2024), whose original application concerns **financial** shocks. The thesis applies the framework to **geopolitical risk** shocks; it does not reproduce the paper's data or empirical results.

The ADL section (thesis Section 4) estimates one response equation at a time. Its model-selection discussion follows Baek and Lee (2022): the distributed-lag length for the shock is tied to the response horizon, while the autoregressive lag length is chosen using BIC. The ADL figures provide a robustness comparison with the system-based SVARX estimates.
